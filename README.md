## Использование отдельных ядер в своем проекте

1. Клонировать данный репозиторий.

2. Скопировать файл-шаблон Bender.yml в отдельную директорию внутри своего проекта и перейти в нее. 

3. Отредактировать файл Bender.yml, выбрав только те ядра, которые необходимы.

4. Получить необходимые зависимости:

```bash
bender checkout
```
5. Подключить ядра в своем коде. 

6. Список файлов выбранных ядер для использования в своих инструментах EDA может быть получен командой: 

```bash
bender script flist
```
